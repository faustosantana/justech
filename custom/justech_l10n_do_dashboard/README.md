# Justech Dominican Fiscal Dashboard

Módulo independiente de **monitoreo y UX fiscal** para el estándar Justech RD.

## Sprint 1 — Alcance

Estructura shell: menú, seguridad, modelo placeholder. Sin KPIs ni widgets aún.

## Instalación

Requiere `justech_l10n_do_base` y `justech_l10n_do_ncf`.

```bash
odoo -i justech_l10n_do_dashboard -d DB --stop-after-init
```
