# Plantillas DGII — República Dominicana

Repositorio interno de **archivos oficiales descargados de la DGII** para Justech Localization RD.

## Contenido

- Archivos `.zip` originales publicados en la [página oficial de Formatos de Envío de Datos](https://dgii.gov.do/herramientas/formularios/formatoEnvioDatos/Paginas/default.aspx).
- `templates.json` — inventario con nombre, código, fechas, URL, SHA256 y versión de cada archivo.

## Uso

Estos archivos son **solo referencia oficial**. Los exportadores de Justech Localization RD **no deben** enviar ni publicar estos ZIP/Excel directamente; deben generar archivos nuevos (TXT, CSV, etc.) usando la estructura documentada en `mappings/`.

## Actualización

Ver `docs/DGII_TEMPLATES.md` para el procedimiento de actualización cuando la DGII publique nuevas versiones.
