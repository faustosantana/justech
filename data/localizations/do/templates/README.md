# Plantillas DGII — República Dominicana

En esta carpeta se almacenarán los **archivos oficiales de la DGII** utilizados como referencia para generar los exportadores de reportes fiscales (606, 607, 608 y formatos relacionados).

Estos archivos son documentación de referencia; no se despliegan directamente en Odoo. Los módulos de localización Justech RD los consumen como base para definir columnas, validaciones y mapeos en `mappings/`.
