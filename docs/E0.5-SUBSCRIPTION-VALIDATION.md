### Neutralización (documentación oficial)

Fuente: [Neutralized database](https://www.odoo.com/documentation/19.0/administration/neutralized_database.html)

> *"Any testing database created is a neutralized database: testing backup databases, duplicate databases, for Odoo.sh: staging and development databases"*

| Funcionalidad desactivada (oficial) | Efecto |
|-------------------------------------|--------|
| Acciones planificadas | Sin cron automático |
| Emails salientes | Sin envío a clientes |
| Sincronización bancaria | Desactivada |
| Proveedores de pago | Desactivados |
| Tokens IAP | Desactivados |
| Website SEO | Desactivado |
| Identificación | Banner rojo |

CLI oficial: `odoo-bin neutralize -d <database>` o `odoo-bin db duplicate <source> <target> -n`

## Arquitectura permanente DEV → TEST → PROD

**No es una arquitectura temporal.** Se mantiene durante toda la vida del proyecto.

```
DEV  ──►  TEST  ──►  PRODUCCIÓN
```

| Ambiente | Rol | Relación con suscripción (oficial) |
|----------|-----|-----------------------------------|
| **DEV** | Construcción y desarrollo custom | Durante implementación: BD candidata a registro. En producción: duplicado neutralizado de PROD |
| **TEST** | UAT y validación | Duplicado neutralizado de BD maestra |
| **PROD** | Operación real | BD con código `M260616306091776` vinculado |

Ver diagrama completo en [ENTERPRISE-LICENSING.md §7](ENTERPRISE-LICENSING.md).

## Errores comunes (documentación oficial)

| Error | Causa documentada | Solución oficial |
|-------|-------------------|------------------|
| Registration error | Código ya vinculado a otra BD | Desvincular o usar duplicado neutralizado |
| Registration error | Contrato no "In Progress" | Contactar Account Manager |
| Registration error | UUID duplicado | Cambiar UUID o ticket soporte |
| Too many users | Usuarios > contratados | Upsell o desactivar usuarios |
| Database expired | Renovación vencida | Renovar en portal |
