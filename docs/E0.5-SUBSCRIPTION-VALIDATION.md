## Resumen de política oficial Odoo

Fuente: [On-premise — Odoo 19.0](https://www.odoo.com/documentation/19.0/administration/on_premise.html)

| Regla oficial | Implicación Hellenia |
|---------------|----------------------|
| **1 código de suscripción = 1 base de datos vinculada** | Solo una BD puede registrar `M260616306091776` a la vez |
| BD de prueba/desarrollo | **Duplicar** BD de producción con opción **neutralize** |
| Múltiples BD con mismo UUID | Prohibido — genera errores de registro/facturación |
| Validación semanal | Salida HTTP a `services.odoo.com:80` permanente |
| Usuarios internos | No exceder usuarios contratados (aviso 30 días si se excede) |
| Estado contrato | Debe mostrar **"In Progress"** en portal Odoo |

### Ambientes DEV / TEST / PROD — restricciones oficiales

Odoo **no permite** vincular el mismo código de suscripción a DEV, TEST y PROD simultáneamente.

**Estrategia oficial recomendada:**

```
PROD  ──(código activo en go-live)──► M260616306091776
         │
         ├── duplicar + neutralize ──► TEST (sin re-registrar código*)
         │
         └── duplicar + neutralize ──► DEV (durante implementación, alternativa)
```

\* Las BD duplicadas heredan el estado Enterprise de la BD origen si se duplican **después** de registrar Enterprise en la BD maestra. Durante implementación inicial, se registra primero en **DEV** y TEST se alimenta por duplicación neutralizada.

**BD neutralizada** ([documentación](https://www.odoo.com/documentation/19.0/administration/neutralized_database.html)):
- Banner rojo identificando entorno de prueba
- Emails salientes desactivados
- Sincronización bancaria desactivada
- Proveedores de pago desactivados
- IAP tokens desactivados
- Acciones planificadas desactivadas

## Matriz decisión: ¿cuántas suscripciones necesitamos?

| Escenario | Suscripciones | Notas |
|-----------|---------------|-------|
| **A — Estándar Odoo** | 1 | DEV registrada → TEST/PROD por duplicación neutralizada |
| **B — Paralelo real** | 2+ | Si DEV y PROD deben estar registradas simultáneamente durante meses |
| **C — Partner** | Variable | Partners Odoo tienen reglas distintas |

**Recomendación Hellenia:** Escenario **A** durante implementación; re-vincular código a PROD en go-live.

## Errores comunes y resolución

| Error | Causa | Solución oficial |
|-------|-------|------------------|
| Registration error | Código ya usado en otra BD | Desvincular o usar duplicado neutralizado |
| Registration error | Contrato no "In Progress" | Contactar Account Manager |
| Registration error | UUID duplicado | Cambiar UUID o ticket soporte Odoo |
| Too many users | Usuarios activos > contratados | Upsell o desactivar usuarios |
| Database expired | Renovación vencida | Renovar en portal |
