## Contenido del archivo Sources (Enterprise)

Según documentación oficial, el archivo Enterprise **no contiene el servidor Community completo** — es la colección de **addons Enterprise** (equivalente al repo `odoo/enterprise`):

> *"The Enterprise git repository does not contain the full Odoo source code. It is only a collection of extra add-ons."*  
> — [Source install](https://www.odoo.com/documentation/19.0/administration/on_premise/source.html)

Tras extraer, debe existir:

```
enterprise/
└── web_enterprise/
    └── __manifest__.py
```

## Procedimiento de descarga y despliegue (para E1 aprobado)

### Paso 1 — Descargar (usuario)

1. Login odoo.com (cuenta suscripción)
2. Download → Odoo 19 → Enterprise → **Sources**
3. Guardar archivo (`.tar.gz` o `.zip` según portal)

### Paso 2 — Entregar archivo (usuario → Cursor, sin SCP al VPS)

Ver **[E0.6c-ENTERPRISE-DELIVERY-FLOW.md](E0.6c-ENTERPRISE-DELIVERY-FLOW.md)** — tres flujos:

| Flujo | Usuario | Cursor en VPS |
|-------|---------|---------------|
| **A** Enlace temporal | Copiar URL de descarga del navegador | `download-enterprise-portal.sh 'URL'` |
| **B** Archivo adjunto | Adjuntar `.tar.gz` al chat Cursor | `receive-enterprise-archive.sh --upload` |
| **C** Manual | Descargar en portal; entregar a Cursor | Igual que A o B |

```bash
# Flujo A (enlace directo al tarball, vigente minutos)
/opt/odoo-projects/hellenia/scripts/download-enterprise-portal.sh 'https://...'

# Flujo B (archivo local → VPS vía agente)
/opt/odoo-projects/hellenia/scripts/receive-enterprise-archive.sh --upload /path/archivo.tar.gz
```

**Validación sin instalar:**

```bash
/opt/odoo-projects/hellenia/scripts/e1a-portal-pipeline.sh --validate-only
```

### Paso 3 — Validar (Cursor — sin instalar)

```bash
/opt/odoo-projects/hellenia/scripts/validate-enterprise-archive.sh \
  /opt/odoo-projects/hellenia/downloads/enterprise/<archivo>.tar.gz --report
```

Checks: integridad, versión 19.0, `web_enterprise`, estructura addons, SHA256. Ver [E0.6c](E0.6c-ENTERPRISE-DELIVERY-FLOW.md).

### Paso 4 — Extraer (Cursor — script, tras aprobación E1a)

```bash
/opt/odoo-projects/hellenia/scripts/extract-enterprise-portal.sh \
  /opt/odoo-projects/hellenia/downloads/enterprise/odoo-19-enterprise-sources.tar.gz
```

El script:

- Valida que el archivo existe
- Extrae a directorio temporal
- Localiza módulos (`web_enterprise/`)
- Copia a `/opt/odoo-projects/hellenia/enterprise/`
- Escribe `enterprise/MANIFEST.txt` con fecha y nombre archivo (sin commit Git)
- Valida `l10n_do_edi`, `l10n_do_reports`, `web_enterprise`

### Paso 5 — E1a (igual que vía Git)

```bash
/opt/odoo-projects/hellenia/scripts/backup-dev.sh
cd /opt/odoo-projects/hellenia/docker/dev
docker compose --env-file ../../config/dev/.env up -d --force-recreate odoo
# ... instalar web_enterprise (ver E1-CHECKLIST.md)
```
