## Flujos certificados v1.0

- **Ventas:** cotización → pedido → factura (B01/B02) → nota crédito (B04) → cobro
- **Compras:** orden → factura proveedor (B11+) → pago
- **Fiscal:** NCF serie B, reportes DGII 606–623
- **Contabilidad:** catálogo Justech, balance, estado de resultados
- **PDF:** factura, cotización, orden de compra

## Antes de operación real

1. Limpiar datos smoke de certificación (facturas/prueba COA3, FISCALRD)
2. Cargar rangos NCF reales DGII
3. Capacitación usuarios clave
